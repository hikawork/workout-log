오늘운동 · FIT LOG 소개 & 사용 가이드

복잡한 로그인이나 무거운 설정 없이, 하루의 유산소·근력·코어·스포츠 운동을 3초 만에 기록하고 달력과 맞춤형 밸런스 그래프로 흐름을 한눈에 확인하는 개인용 운동 기록 트래커입니다.

✨ 핵심 기능 한눈에 보기

⚡ 3초 빠른 기록

시간(분·초 + 거리)과 횟수×세트(+ 중량) 모드를 종목별로 자동 지원하며, 누적(+) 버튼과 초기화 버튼으로 손쉽게 입력합니다.

📅 일별 달력 & 순서 편집

월간 달력에서 운동한 날을 한눈에 보고, 같은 날 여러 번 운동한 기록도 드래그 앤 드롭으로 원하는 순서대로 정리할 수 있습니다.

🕸️ 맞춤형 밸런스 그래프

유산소, 근력, 코어, HIIT, 스포츠, 야외활동 등 최대 11개 카테고리 중 3~8개를 직접 골라 나만의 원형 밸런스 차트를 구성합니다.

💾 로컬 파일 안전 백업

모든 기록은 내 기기에 저장되며, JSON 파일 내보내기·불러오기와 PC 로컬 파일 실시간 자동저장 기능을 제공합니다.

📖 화면별 사용 방법

1
운동 기록하기

상단에서 날짜를 고르고 종목 카드를 누른 뒤 시간 또는 횟수·세트를 입력하세요. +5분, +10회 버튼은 현재 값에 누적해서 더해지며, 한 종목을 하루에 여러 번 나눠 등록할 수도 있습니다.

2
나만의 종목 추가 & 순서 변경

종목 목록의 + 종목 추가 버튼으로 원하는 운동과 카테고리·아이콘을 만들 수 있고, ⚙️ 종목 편집을 켜서 기본·사용자 종목의 수정/삭제 및 순서 드래그가 가능합니다.

3
일별 달력 보기

하단 일별 달력 탭에서 월별 출석 현황을 확인하고 날짜를 누르면 해당 날의 전체 운동 내역을 확인·수정·삭제할 수 있습니다.

4
운동 통계 & 밸런스 설정

운동 통계 탭에서 이번 주 / 이번 달 / 최근 30일 / 전체 기간별 출석일·시간·세트 수·종목 순위를 확인할 수 있으며, ⚙️ 항목 구성에서 밸런스 그래프 축(3~8개)을 바꿀 수 있습니다.

❓ 자주 묻는 질문 (FAQ)

Q. 회원가입이나 로그인 없이 데이터는 어디에 저장되나요?

모든 기록과 종목 설정은 별도 서버로 전송되지 않고 사용자의 기기(브라우저 저장소)에만 저장됩니다. 중요한 기록을 오래 보관하려면 상단 백업/로컬 파일 기능을 이용해 JSON 파일로 저장해 두시는 것을 권장합니다.

Q. 하루에 같은 운동을 오전·오후로 두 번 이상 기록할 수 있나요?

네, 가능합니다. 같은 날짜에 같은 종목을 다시 선택해도 항상 새 기록 입력 상태로 열리므로 하루에 여러 세션을 제한 없이 추가할 수 있습니다. 기존 기록을 고치고 싶을 때는 하단 목록에서 해당 기록이나 수정 버튼을 눌러 주세요.

Q. PC에서 브라우저를 새로고침하면 로컬 파일 연결을 다시 해야 하나요?

파일 탐색기에서 파일을 다시 고를 필요는 없습니다. 브라우저 보안 정책상 새로고침 후 쓰기 권한 확인이 필요할 때 상단 배너가 로컬 파일 재연결 필요로 바뀌며, 🔗 1클릭 재연결 버튼만 누르면 기존 파일이 바로 다시 연결됩니다.

Q. 등산, 요가, 복싱 같은 종목도 밸런스 그래프에 따로 표시할 수 있나요?

네. 운동 통계 > 내 운동 밸런스 > ⚙️ 항목 구성에서 코어·밸런스, HIIT, 파워·민첩성, 가동성·회복, 복싱·무술, 마인드바디(요가·필라테스), 야외·일상(등산 등) 중 원하는 3~8개 항목을 선택해 그래프에 반영할 수 있습니다.

Q. 스마트폰 홈 화면에 앱처럼 추가해서 쓸 수 있나요?

네. iPhone Safari에서는 하단 공유 버튼 > 홈 화면에 추가, Android Chrome에서는 우측 상단 메뉴 > 홈 화면에 추가(또는 앱 설치)를 누르면 일반 앱처럼 전체 화면 아이콘으로 실행됩니다.

Q. 기기를 바꾸거나 브라우저를 옮길 때 기록은 어떻게 이동하나요?

기존 기기의 운동 통계 > 데이터 & 백업 관리 > 다른 이름으로 백업 저장(JSON)으로 파일을 저장한 뒤, 새 기기에서 백업 불러오기로 해당 JSON 파일을 선택하면 모든 기록과 커스텀 종목이 그대로 복원됩니다.
